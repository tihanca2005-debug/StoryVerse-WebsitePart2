   Description
StoryVerse is a book movie rental shop website located at 123 Jorissen Street, Braamfontein.

       Pages
- index.html - Home with banner
- about.html - About us
- products.html - Books grid (responsive)
- enquiry.html - Form for customers to enquire about books and movies
- contact.html - Contact details, map and validation
